# Production Access Policy

Production system access must be approved before access
is granted.

Engineers must obtain approval from their engineering
manager and the relevant production system owner.

Privileged production access must use an individually
assigned account. Shared accounts are prohibited.

Production access should follow least-privilege principles.

Access must be reviewed periodically and revoked when it
is no longer required.

Emergency access may be granted through the break-glass
procedure. Emergency access must be documented and
reviewed after use.
